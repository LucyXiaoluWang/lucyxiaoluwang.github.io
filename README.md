# Lucy Xiaolu Wang — Personal Website

Source for [lucyxiaoluwang.com](https://www.lucyxiaoluwang.com), hosted on GitHub Pages.

A self-contained static site — one HTML file, no external fonts or scripts.

## Editing

Everything is in `index.html`. To add a paper, copy one `<div class="paper">…</div>` block and edit the text/links. You can also edit directly on GitHub's web editor (pencil icon).
